## Form Aduan

Untuk memulai percakapan aduan, pengguna dapat mengklik floating action button di pojok kanan bawah halaman utama amdalnet, kemudian pilih icon chat/percakapan yang paling atas.

![](https://files.readme.io/863966297778ee93575061b9f276146c5d157e283557011a12ac02c731243028-image.png)

<br />

Setelah itu akan muncul formulir dialog yang harus pengguna isi. Beberapa input yang wajib pengguna isi antara lain:

- Nama
- Nama Instansi/Perusahaan
- Email
- Nomor Whatsapp/Telepon
- Nomor Registrasi Amdalnet (Opsional)
- Pesan (maks. 1000 karakter), dapat mengandung emoji dan link/URL

Adapun beberapa kolom input dan fitur opsional antara lain:

- Nomor Registrasi AMDALNET
- File Lampiran dengan ketentuan:
  | Jenis   | Format         | Batas ukuran per file |
  | ------- | -------------- | --------------------- |
  | Gambar  | JPG, JPEG, PNG | 10 MB                 |
  | Dokumen | PDF, DOCX      | 10 MB                 |
  | Arsip   | ZIP            | 10 MB                 |
  | Video   | MP4, MOV, WEBM | 50 MB                 |

<Image src="https://files.readme.io/1fb0ddabef5d3147bcefb33ff3e9e4e84f88cb89445d63f07343b68b778552c9-image.png" align="center" width="80%" />

Setelah pengguna mengisi kolom yang wajib dan mengisi pesan dengan keluhan yang dihadapi, pengguna dapat menekan tombol "Kirim Pesan" di kanan bawah dialog. Jika berhasil pengguna akan mendapatkan  notifikasi di bagian atas dan akan di-redirect ke halaman chat.

<Callout icon="far fa-circle-info" theme="warn">
  ### Tab baru tidak terbuka?

  Browser mungkin memblokir pop-up. Izinkan pop-up untuk situs AMDALNET, atau buka halaman chat melalui tautan di email konfirmasi (lihat Notifikasi Email).
</Callout>
