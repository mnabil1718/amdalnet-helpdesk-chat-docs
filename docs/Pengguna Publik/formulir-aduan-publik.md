## Form Aduan

Untuk memulai percakapan aduan, pengguna dapat mengklik floating action button di pojok kanan bawah halaman utama amdalnet, kemudian pilih icon chat/percakapan yang paling atas.

![](https://files.readme.io/863966297778ee93575061b9f276146c5d157e283557011a12ac02c731243028-image.png)

<br />

Setelah itu akan muncul formulir dialog yang harus pengguna isi. Beberapa input yang wajib pengguna isi antara lain:

- Nama
- Nama Instansi/Perusahaan
- Email
- Nomor Whatsapp/Telepon
- Pesan (maks. 1000 karakter), dapat mengandung emoji dan link/URL

Adapun beberapa kolom input dan fitur opsional antara lain:

- Nomor Registrasi AMDALNET
- File Lampiran dengan ketentuan:
  - Maks. 5 File
  - Dapat berupa dokumen: .docx, .zip, .pdf
  - Dapat berupa gambar: .jpg, .png
  - Dapat berupa video: .mp4, .mov, .webm
  - Untuk setiap gambar dan dokumen maksimum ukuran 10 MB
  - Untuk setiap video maksimum ukuran 50 MB

![](https://files.readme.io/b0cc5697d63bb7eb43ce8a46fd5dfb2ca885dd5a3282975bfb090bbb9eb42199-image.png)

Setelah pengguna mengisi kolom yang wajib dan mengisi pesan dengan keluhan yang dihadapi, pengguna dapat menekan tombol "Kirim Pesan" di kanan bawah dialog. Jika berhasil pengguna akan mendapatkan notifikasi di bagian atas dan akan di-redirect ke halaman chat.

## Halaman Chat

![](https://files.readme.io/ba5bb0a5447d9a806b320c934cd46736667bb4659e981c4baa772c56fb6e33b6-image.png)

Setelah mengisi formulir aduan, pengguna akan otomatis diarahkan ke halaman chat aduan dimana pengguna dapat berkirim pesan dan lampiran kepada personalia helpdesk AMDALNET. Jika halaman tertutup atau tidak langsung dapat diakses pengguna dapat melihat email masuk dari AMDALNET dengan subjek "Pesan Anda Telah diterima - AMDALNET \[Kode Chat]". Pengguna dapat mengakses halaman caht dengan mengklik tombol "Lanjutkan Percakapan" atau direct link di bawah tombol.

> Saat ini fitur chat belum real-time sehingga pengguna maupun helpdesk harus menekan tombol "refresh" di kanan atas untuk mendapatkan pesan terbaru. Notifikasi balasan real-time hanya diterima pengguna melalui email.

![](https://files.readme.io/91480b2f854fa43a76b4def1dcfc26bacc9a6f714f983d4d51f35dc5b54923fb-image.png)

<Callout icon="far fa-seal-exclamation" theme="error">
  ### Cek Spam Inbox

  Email mungkin dapat masuk ke spam inbox email pengguna. Hal ini diluar kendali AMDALNET sehingga pengguna harus melihat folder SPAM untuk berjaga-jaga.
</Callout>
