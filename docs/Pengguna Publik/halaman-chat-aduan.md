Setelah mengisi formulir aduan, pengguna akan otomatis diarahkan ke halaman chat aduan dimana pengguna dapat berkirim pesan dan lampiran kepada personalia helpdesk AMDALNET.&#x20;

<Callout icon="🚧" theme="warn">
  ### Perhatian

  Saat ini fitur chat belum real-time sehingga pengguna maupun helpdesk harus menekan tombol "refresh" di kanan atas untuk mendapatkan pesan terbaru. Notifikasi balasan real-time hanya diterima pengguna melalui email.
</Callout>

![](https://files.readme.io/ba5bb0a5447d9a806b320c934cd46736667bb4659e981c4baa772c56fb6e33b6-image.png)

## Lampiran

Anda dapat berkirim lampiran dengan personalia helpdesk AMDALNET dengan meng-klik ikon lampiran di pojok kiri input chat.

![](https://files.readme.io/b5bf96c18f867133c7fa09692a547ec2f12e2a3adff15b89c3b000cdebb9ee3b-image.png)

Adapun, ketentuan lampiran yang dapat Anda kirimkan adalah sebagai berikut:

| Jenis   | Format         | Batas ukuran per file |
| ------- | -------------- | --------------------- |
| Gambar  | JPG, JPEG, PNG | 10 MB                 |
| Dokumen | PDF, DOCX      | 10 MB                 |
| Arsip   | ZIP            | 10 MB                 |
| Video   | MP4, MOV, WEBM | 50 MB                 |

Setelah klik ikon lampiran, pop-up pemilihan berkas akan muncul dan Anda dapat memilih berkas dari penyimpanan lokal Anda berdasarkan ketentuan lampiran di atas. Setelah selesai Anda masih dapat menambah atau menghapus berkas yang kurang sesuai.&#x20;

![](https://files.readme.io/94179e2124a96147f2f559fddadffa2377eb399e6d1a8c46c654312319db0fca-image.png)

Setelah semua sesuai keinginan Anda, klik ikon pesawat kertas di sebelah kanan input chat.

![](https://files.readme.io/4442559015995b6ea147ecfa3a91c034d2942db40e27ad199cc5da6a664df55b-image.png)

Setelah lampiran terkirim, Anda dapat melakukan beberapa aksi pada lampiran. Jika Anda klik lampiran, maka lampiran akan otomatis terunduh di komputer lokal Anda. Anda juka dapat meng-klik ikon dropdown untuk mengunduh dan menyalin link lampiran. Menyalin link lampiran berarti Anda dapat dengan leluasa membagikan lampiran ke sesi chat baru, personel helpdesk lain, atau bahkan ke sistem lain.

![](https://files.readme.io/bf05338494d70fe6f2bcb618a014b35d9309885784113feb66f6933d52bef4ac-image.png)

## Emoji

Anda dapat mengirimkan emoji bersamaan dengan pesan chat Anda. Cukup tekan ikon emoji (smiley) dan popup koleksi emoji akan muncul. Pilih emoji yang Anda sukai.

![](https://files.readme.io/22fc3504be8df027689c4ab93c1da6fcce52213821b1535f74bcdc670730e236-image.png)

## Link

Anda juga dapat mengirimkan link bersamaan dengan pesan chat Anda. Cukup ketik atau copy-paste link yang Anda ingin kirim. Setelah terkirim, sistem akan auto-highlight link sehingga mudah diidentifikasi dan klik.

![](https://files.readme.io/b420927fcc5ead29f12087c2ff57a6a69df0b83cdabb20a759752b93563f1e60-image.png)
