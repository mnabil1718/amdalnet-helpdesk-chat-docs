# Pengguna Publik


## Formulir Aduan Publik

## Form Aduan

Untuk memulai percakapan aduan, pengguna dapat mengklik floating action button di pojok kanan bawah halaman utama amdalnet, kemudian pilih icon chat/percakapan yang paling atas.

![](https://files.readme.io/863966297778ee93575061b9f276146c5d157e283557011a12ac02c731243028-image.png)

<br />

Setelah itu akan muncul formulir dialog yang harus pengguna isi. Beberapa input yang wajib pengguna isi antara lain:

- Nama
- Nama Instansi/Perusahaan
- Email
- Nomor Whatsapp/Telepon
- Nomor Registrasi Amdalnet (Opsional)
- Pesan (maks. 1000 karakter), dapat mengandung emoji dan link/URL

Adapun beberapa kolom input dan fitur opsional antara lain:

- Nomor Registrasi AMDALNET
- File Lampiran dengan ketentuan:
  | Jenis   | Format         | Batas ukuran per file |
  | ------- | -------------- | --------------------- |
  | Gambar  | JPG, JPEG, PNG | 10 MB                 |
  | Dokumen | PDF, DOCX      | 10 MB                 |
  | Arsip   | ZIP            | 10 MB                 |
  | Video   | MP4, MOV, WEBM | 50 MB                 |

<Image src="https://files.readme.io/1fb0ddabef5d3147bcefb33ff3e9e4e84f88cb89445d63f07343b68b778552c9-image.png" align="center" width="80%" />

Setelah pengguna mengisi kolom yang wajib dan mengisi pesan dengan keluhan yang dihadapi, pengguna dapat menekan tombol "Kirim Pesan" di kanan bawah dialog. Jika berhasil pengguna akan mendapatkan  notifikasi di bagian atas dan akan di-redirect ke halaman chat.

<Callout icon="far fa-circle-info" theme="warn">
  ### Tab baru tidak terbuka?

  Browser mungkin memblokir pop-up. Izinkan pop-up untuk situs AMDALNET, atau buka halaman chat melalui tautan di email konfirmasi (lihat Notifikasi Email).
</Callout>

![](https://files.readme.io/20785bb3b7ce8d6533117c9bd65ba8247d5964b6d5bfc0de25fba86e316cc53d-image.png)



## Halaman Chat Aduan

Setelah mengisi formulir aduan, pengguna akan otomatis diarahkan ke halaman chat aduan dimana pengguna dapat berkirim pesan dan lampiran kepada personalia helpdesk AMDALNET.&#x20;

<Callout icon="🚧" theme="warn">
  ### Perhatian

  Saat ini fitur chat belum real-time sehingga pengguna maupun helpdesk harus menekan tombol "refresh" di kanan atas untuk mendapatkan pesan terbaru. Notifikasi balasan real-time hanya diterima pengguna melalui email.
</Callout>

![](https://files.readme.io/ba5bb0a5447d9a806b320c934cd46736667bb4659e981c4baa772c56fb6e33b6-image.png)

## Lampiran

Anda dapat berkirim lampiran dengan personalia helpdesk AMDALNET dengan meng-klik ikon lampiran di pojok kiri input chat.

![](https://files.readme.io/b5bf96c18f867133c7fa09692a547ec2f12e2a3adff15b89c3b000cdebb9ee3b-image.png)

Adapun, ketentuan lampiran yang dapat Anda kirimkan adalah sebagai berikut:

| Jenis   | Format         | Batas ukuran per file |
| ------- | -------------- | --------------------- |
| Gambar  | JPG, JPEG, PNG | 10 MB                 |
| Dokumen | PDF, DOCX      | 10 MB                 |
| Arsip   | ZIP            | 10 MB                 |
| Video   | MP4, MOV, WEBM | 50 MB                 |

Setelah klik ikon lampiran, pop-up pemilihan berkas akan muncul dan Anda dapat memilih berkas dari penyimpanan lokal Anda berdasarkan ketentuan lampiran di atas. Setelah selesai Anda masih dapat menambah atau menghapus berkas yang kurang sesuai.&#x20;

![](https://files.readme.io/94179e2124a96147f2f559fddadffa2377eb399e6d1a8c46c654312319db0fca-image.png)

Setelah semua sesuai keinginan Anda, klik ikon pesawat kertas di sebelah kanan input chat.

![](https://files.readme.io/4442559015995b6ea147ecfa3a91c034d2942db40e27ad199cc5da6a664df55b-image.png)

Setelah lampiran terkirim, Anda dapat melakukan beberapa aksi pada lampiran. Jika Anda klik lampiran, maka lampiran akan otomatis terunduh di komputer lokal Anda. Anda juka dapat meng-klik ikon dropdown untuk mengunduh dan menyalin link lampiran. Menyalin link lampiran berarti Anda dapat dengan leluasa membagikan lampiran ke sesi chat baru, personel helpdesk lain, atau bahkan ke sistem lain.

![](https://files.readme.io/bf05338494d70fe6f2bcb618a014b35d9309885784113feb66f6933d52bef4ac-image.png)

## Emoji

## Notifikasi Email

Jika halaman tertutup atau tidak langsung dapat diakses pengguna dapat melihat email masuk dari AMDALNET. Pengguna juga harus berhati-hati karena email yang dikirim mungkin masuk ke folder SPAM pada inbox email.

<Callout icon="far fa-seal-exclamation" theme="error">
  ### Cek Spam Inbox

  Email mungkin dapat masuk ke spam inbox email pengguna. Hal ini diluar kendali AMDALNET sehingga pengguna harus melihat folder SPAM untuk berjaga-jaga.
</Callout>

Pengguna akan mendapatkan 4 macam email dari fitur chat aduan AMDALNET pada beberapa titik percakapan:

### Submit Form Aduan

Kirim Pesan pertama kali dari form aduan. Aksi ini akan membuat sesi aduan/percakapan baru dengan personalia helpdesk AMDALNET.

![](https://files.readme.io/91480b2f854fa43a76b4def1dcfc26bacc9a6f714f983d4d51f35dc5b54923fb-image.png)

Anda akan mendapatkan email dengan subject "Pesan Anda telah diterima - AMDALNET \[code]". Di dalam email berisi code chat, dan tombol "Lanjutkan Percakapan". Anda dapat klik tombol tersebut untuk masuk ke chat room. Jika tombol tidak berfungsi Anda juga dapat klik direct link di bawal tombol untuk masuk ke chat room.

### Auto-reply diluar Jam Operasion

Anda juga akan menerima pesan otomatis jika Anda submit form aduan diluar jam operasional dan hari libur (hari libur nasional/cuti bersama). Email ini akan dikirim sesaat setelah email submit form aduan secara otomatis.

![](https://files.readme.io/8ce27879d6980bd7d9796948881a642a6783ff7fb953ad3ce8c83fdd9b4f38c5-image.png)

### Balasan dari Helpdesk

Anda akan menerima email saat helpdesk telah membalas pesan Anda. Isi email juga akan menyertakan log percakapan secara kronologis.

![](https://files.readme.io/74cf35285f023c1fd9e4e4f2bcd5997e065c32f2c3ac40e3c712c3043f2ea1e6-image.png)

### Chat diakhiri Helpdesk

Anda akan menerima email saat helpdesk mengakhiri chat dengan Anda. Helpdesk mungkin mengakhiri chat bila satu dari tiga kondisi ini terpenuhi:

- Permasalahan atau topik percakapan telah selesai
- Percakapan melanggar ketentuan dan pedoman aduan AMDALNET
- Anda tidak merespon percakapan selama 4 hari

Isi email hampir sama dengan balasan helpdesk, namun tombol diganti dengan "Mulai Chat Baru" dan mengarahkan Anda ke halaman utama AMDALNET. Dibawahnya Anda juga akan menemukan log percakapan lengkap secara kronologis.

![](https://files.readme.io/4670da5bf3c20ecbb761806a715d0c95bf6f771b9f178aa00558bc7a7553504c-image.png)

# Helpdesk


## Mengelola Daftar Percakapan

## Tampilan Tabel

Helpdesk dapat melihat aduan chat secara kronologis melalui tampilan tabel yang tersedia. Terdapat beberapa kolom yang ditunjukkan dalam tabel:

1. Nomor urut: nomor sekuensial dimulai dari angka 1 untuk mempermudah mengurutkan chat aduan masuk
2. ID: kode chat unik untuk tiap chat masuk. Juga merepresentasikan tiket chat aduan pengguna.
3. Tanggal mulai: tanggal dan waktu mulai chat aduan masuk
4. Nama: Nama pengguna yang mengadukan keluhan
5. Email: Email pengguna yang mengadukan chat
6. Nama Instansi: Nama instansi/perusahaan asal pengguna
7. Update terakhir: Snippet pesan terakhir dan kapan pesan tersebut dikirim
8. Status: status chat, dapat bernilai "Menunggu user", "Menunggu admin", atau "Selesai".
9. Penugasan: personel chat agent yang harus menangani chat aduan tersebut
10. Aksi masuk chat: masuk ke chat room untuk membalas pesan aduan.

![](https://files.readme.io/deb50cc8ff58a5a7542581b457c8a7287155d5909d0dd1bdee94c871363b4a5f-image.png)

### Mencari Percakapan

![](https://files.readme.io/198e2c646223efc945baebfca6588059dec45ac731603ae1eb1288d3699f15c4-Screenshot_2026-10-22_at_16.41.46.png)

Gunakan kolom pencarian untuk mencari berdasarkan:

- Kode chat.
- Nama pengguna.
- Email.
- Nomor telepon.
- Nomor registrasi AMDALNET.
- Nama instansi.

Langkah penggunaan:

1. Masukkan kata kunci.
2. Tunggu hasil pencarian atau klik tombol pencarian.
3. Sistem menampilkan percakapan yang sesuai.

Pencarian daftar chat tidak mencari seluruh isi pesan percakapan.

### Memfilter Status

![](https://files.readme.io/7200ecb3d31fb3448ab5e6402187af00da8257696affc7e382b99319e311a075-Screenshot_2026-10-22_at_16.42.53.png)

Admin dapat memilih satu atau beberapa status:

| Status         | Arti                                                 |
| -------------- | ---------------------------------------------------- |
| Menunggu Admin | Percakapan sedang menunggu tanggapan admin           |
| Menunggu User  | Admin sudah membalas dan menunggu tanggapan pengguna |
| Selesai        | Percakapan sudah diakhiri                            |

Status **Menunggu Admin** tidak sama dengan penanda belum dibaca. Membuka percakapan tidak otomatis mengubahnya menjadi **Menunggu User**.

### Memfilter Agen

![](https://files.readme.io/08d17f8269acd02367800559de6c1734f408269162535da0e6270d4ba5c6fa79-Screenshot_2026-10-22_at_16.44.15.png)

Admin dapat:

- Memilih satu atau beberapa agen.
- Mencari opsi agen berdasarkan nama atau email.
- Memilih **Belum ditugaskan**.
- Menggabungkan pilihan agen dengan percakapan yang belum ditugaskan.

Filter agen dapat menampilkan agen nonaktif untuk membantu penelusuran percakapan lama.

### Memfilter Tanggal

![](https://files.readme.io/201c51014b6cf161d9e07fa8a1da39a08e1b85c677a12d657eb6f2d087321630-Screenshot_2026-10-22_at_16.44.45.png)

1. Pilih tanggal awal.
2. Pilih tanggal akhir.
3. Sistem menyaring berdasarkan tanggal mulai percakapan.

Tanggal akhir tidak boleh lebih awal daripada tanggal awal.

### Mereset Filter

Klik **Reset** untuk mengosongkan pencarian, status, rentang tanggal, dan filter agen.

Pada akun admin, reset mengembalikan daftar ke cakupan semua agen.



## Membuka dan Membalas Percakapan

## Membuka dan Membalas Percakapan

### 1. Membuka Chat

![](https://files.readme.io/51087e486ac7abf9e2b303fb7d2ff4d414f54a194cb5e010d8178692dc374e0c-Screenshot_2026-10-22_at_16.49.27.png)

Pada kolom Aksi:

- Klik **Masuk Chat** untuk percakapan yang belum selesai.
- Klik **Lihat Chat** untuk percakapan yang sudah selesai.

Percakapan dibuka pada tab atau jendela browser terpisah, bergantung pada pengaturan browser. Membuka kode chat yang sama kembali akan menggunakan tab bernama sama apabila masih tersedia.

### 2. Informasi pada Ruang Chat

![](https://files.readme.io/840060502306c2fcba082e9d8902af77644d55dc2407c5334fc4e769ae136b1c-Screenshot_2026-10-22_at_16.50.58.png)

Admin dapat melihat:

- Nama pengguna.
- Kode chat.
- Email dan nomor telepon.
- Status percakapan.
- Riwayat pesan dan lampiran.
- Waktu pesan serta pengelompokan berdasarkan tanggal.
- Informasi waktu penutupan jika chat sudah selesai.

Klik ikon salin di samping kode chat untuk menyalin kode tersebut.

### 3. Memuat Pesan Terbaru


<Image src="https://files.readme.io/840060502306c2fcba082e9d8902af77644d55dc2407c5334fc4e769ae136b1c-Screenshot_2026-10-22_at_16.50.58.png" align="center" />

Klik tombol **Muat ulang chat** di kanan atas.

Pada implementasi saat ini, admin perlu menggunakan tombol tersebut untuk melihat pesan masuk terbaru. Jangan mengasumsikan pesan pengguna selalu muncul otomatis secara realtime.

### 4. Mengirim Pesan

1. Ketik balasan pada kolom pesan.
2. Klik tombol kirim.
3. Sistem menyimpan balasan dan memperbarui percakapan.

Pada perangkat desktop:

- Enter digunakan untuk mengirim.
- Shift + Enter digunakan untuk membuat baris baru.

Pada perangkat sentuh, Enter digunakan untuk membuat baris baru; gunakan tombol kirim.

Kolom pesan pada frontend saat ini dibatasi maksimal **1.000 karakter**.

Setelah admin membalas, status percakapan menjadi **Menunggu User**.

Sistem menjalankan pengiriman email notifikasi kepada pengguna. Penerimaan email bergantung pada konfigurasi SMTP dan layanan email penerima.

### 5. Menggunakan Emoji

1. Klik ikon Emoji.
2. Pilih emoji.
3. Emoji disisipkan pada posisi kursor atau menggantikan teks yang dipilih.
4. Kirim pesan seperti biasa.

### 6. Membuka Tautan

Tautan yang dikenali pada pesan ditampilkan sebagai link yang dapat diklik.

- Tautan ke domain pemerintah `.go.id` dibuka langsung.
- Tautan ke domain lain menampilkan konfirmasi sebelum dibuka.

Admin tetap perlu memeriksa tujuan tautan dan mengenali pengirimnya.

## Mengirim dan Mengakses Lampiran

## Mengirim dan Mengakses Lampiran

### 1. Format dan Batas Lampiran

| Jenis   | Format         | Batas ukuran per file |
| ------- | -------------- | --------------------- |
| Gambar  | JPG, JPEG, PNG | 10 MB                 |
| Dokumen | PDF, DOCX      | 10 MB                 |
| Arsip   | ZIP            | 10 MB                 |
| Video   | MP4, MOV, WEBM | 50 MB                 |

Maksimal **5 file** dapat dipilih dalam satu batch pengiriman pada frontend.

Server tetap memvalidasi format, ukuran, dan kesesuaian isi file. Mengganti ekstensi nama file tidak menjamin file dapat diterima.

### 2. Menambahkan Lampiran

Admin dapat menggunakan:

- Tombol Lampiran, kemudian memilih Gambar, Video, atau Dokumen.
- Drag and drop file ke area percakapan.

Setelah dipilih, sistem menampilkan panel lampiran.

### 3. Meninjau Lampiran Sebelum Dikirim

Pada panel lampiran, admin dapat:

- Melihat preview gambar.
- Melihat nama dan ukuran dokumen atau video.
- Berpindah antarfile melalui thumbnail.
- Menambahkan keterangan pada masing-masing file.
- Menambahkan file sampai batas maksimum.
- Menghapus file melalui tombol silang.
- Membatalkan seluruh pilihan lampiran.
- Mengirim lampiran tanpa teks apabila diperlukan.

Preview dokumen dan video pada panel ini berupa informasi file, bukan pembaca dokumen atau pemutar video.

### 4. Memantau Pengiriman

Saat mengunggah lampiran, sistem menampilkan:

- Status menunggu.
- Persentase upload.
- Status pemrosesan.
- Pesan kegagalan jika terjadi kesalahan.

Admin dapat membatalkan upload yang masih dapat dibatalkan dan mengirim ulang file yang gagal.

Pembatalan upload bukan tindakan untuk menghapus lampiran yang sudah berhasil tersimpan.

### 5. Mengakses Lampiran yang Sudah Terkirim

Pada lampiran di riwayat chat, admin dapat:

- Membuka gambar di tab baru.
- Mengunduh file.
- Memilih menu **Unduh**.
- Memilih menu **Salin link**.

![](https://files.readme.io/bf05338494d70fe6f2bcb618a014b35d9309885784113feb66f6933d52bef4ac-image.png)

Tautan lampiran dapat dibagikan. Perlakukan tautan tersebut sebagai informasi sensitif dan jangan membagikannya kepada pihak yang tidak berwenang.



## Menggunakan Template Balasan

## Menggunakan Template Balasan

![](https://files.readme.io/89547d57844f4f8d83c8a1e9683c13d1e93e861a14626c9816882d617177dc70-Screenshot_2026-10-22_at_16.55.47.png)

### 1. Memilih Template dari Menu

1. Klik tombol Menu di dekat kolom pesan.
2. Pilih template balasan.
3. Tinjau dan sesuaikan isinya.
4. Kirim pesan.

Template membantu pengisian pesan; pemilihannya tidak langsung mengirim pesan.

### 2. Mencari Template dengan Perintah Slash

1. Ketik `/` pada awal pesan atau setelah spasi.
2. Lanjutkan dengan kata dari judul template.
3. Pilih salah satu hasil.

Navigasi hasil dapat dilakukan menggunakan:

- Panah atas dan bawah untuk memilih.
- Enter atau Tab untuk memasukkan template.
- Escape untuk menutup daftar.

### 3. Mereset Pesan Template

Gunakan **Reset Pesan** pada menu untuk mengosongkan pesan yang terisi dari template.

### 4. Template Salam Penutup

Template dengan slot `salam-penutup` memiliki perilaku khusus:

- Mengisi pesan penutup.
- Mengaktifkan mode akhiri chat.
- Memerlukan konfirmasi ketika pesan dikirim.

Periksa mode pengiriman sebelum menekan tombol kirim.

## Mengakhiri Percakapan

## Mengakhiri Percakapan

![](https://files.readme.io/89547d57844f4f8d83c8a1e9683c13d1e93e861a14626c9816882d617177dc70-Screenshot_2026-10-22_at_16.55.47.png)

![](https://files.readme.io/3a39729eaac5ba757c852e6a0ca403d0be2a52078f21e0bc0f277c2b030e6c66-Screenshot_2026-10-22_at_16.56.39.png)

1. Buka menu pada kolom pesan.
2. Pilih **Akhiri chat**.
3. Tinjau template penutup jika tersedia, atau tulis pesan terakhir.
4. Klik kirim.
5. Setujui konfirmasi **Kirim & Akhiri**.

Admin dapat membatalkan mode penutupan melalui **Batal akhiri chat** sebelum mengirim.

Setelah penutupan berhasil:

- Status berubah menjadi **Selesai**.
- Riwayat tetap dapat dibaca.
- Pengiriman pesan baru dinonaktifkan.
- Penugasan tidak dapat diubah.
- Sistem menjalankan pengiriman email penutupan kepada pengguna.

Jika ada lampiran yang gagal terkirim, chat belum diakhiri.

Jika pesan sudah terkirim tetapi penutupan gagal, sistem menampilkan pemberitahuan dan chat dapat tetap terbuka.

> Tidak tersedia fitur membuka kembali chat yang sudah selesai pada implementasi ini.



## Pengaturan Chat

## Pengaturan Chat

![](https://files.readme.io/bba42b788967351bede76309c7b8ef0f0441d90b51b885756113d8d736211efb-Screenshot_2026-10-22_at_16.57.46.png)

Klik tombol **Pengaturan** pada halaman daftar Chat Bantuan.

Pengaturan terdiri dari lima tab:

1. Template Chat.
2. SMTP.
3. Agen Chat.
4. Jam Operasional.
5. Hari Libur.

### 1. Template Chat

![](https://files.readme.io/eb006ff40486f520f190950a0e3800c530b977d12dd7a2145c3a9c4b78e8aaeb-Screenshot_2026-10-22_at_16.58.46.png)

![](https://files.readme.io/dd400d855f34d5420539fdc0e0454801ae9d099618d172aeb6cb3bd6b220fcc8-Screenshot_2026-10-22_at_16.58.19.png)

Admin dapat melihat, menambahkan, mengubah, dan menghapus template.

#### Menambahkan Template

1. Buka tab Template Chat.
2. Klik **Tambah Template**.
3. Isi judul, slot, dan isi balasan.
4. Klik **Simpan**.

Batas pada form frontend:

| Field | Ketentuan                      |
| ----- | ------------------------------ |
| Judul | Wajib, maksimal 100 karakter   |
| Slot  | Wajib, maksimal 20 karakter    |
| Isi   | Wajib, maksimal 1.000 karakter |

Slot menggunakan huruf kecil, angka, tanda hubung, atau underscore, dengan awal dan akhir berupa huruf/angka.

Rekomendasi slot:

- `salam-pembuka`
- `jawaban-cepat`
- `tindak-lanjut`
- `salam-penutup`
- `luar-jam-kerja`

Judul dan slot yang sudah digunakan dapat ditolak oleh sistem.

#### Mengubah atau Menghapus Template

1. Klik menu opsi pada kartu template.
2. Pilih **Edit** atau **Hapus**.
3. Simpan perubahan atau konfirmasi penghapusan.

Template pada ruang chat dimuat saat digunakan. Setelah perubahan pengaturan, muat ulang halaman ruang chat jika daftar template belum diperbarui.

### 2. SMTP

![](https://files.readme.io/2db4de1cbce186765d5580b6fdf907e7cf9a6e54887f9ba539db9c4734b78584-Screenshot_2026-10-22_at_16.59.09.png)

![](https://files.readme.io/511d0efbbadabee5d76fad9b98f7a1aef3b3db444f87b003cff17842507d63c7-Screenshot_2026-10-22_at_16.59.22.png)

SMTP digunakan untuk mengirim email notifikasi chat.

Admin dapat:

- Melihat daftar akun SMTP.
- Menambahkan akun.
- Mengubah konfigurasi.
- Mengirim email pengujian.
- Mengganti akun default.
- Menghapus akun non-default.

#### Menambahkan atau Mengubah SMTP

Isi konfigurasi berikut:

- Nama akun.
- Nama pengirim.
- Alamat email pengirim.
- Host SMTP.
- Port.
- Enkripsi: tanpa enkripsi, TLS, atau SSL.
- Username.
- Password.

#### Mengaktifkan atau Menonaktifkan Agen

Gunakan switch pada kolom Status.

Agen nonaktif tidak dapat dipilih sebagai tujuan penugasan baru.

#### Menghapus Agen

Klik **Hapus**, lalu ikuti konfirmasi.

Penghapusan ini menghapus keanggotaan agen, bukan akun pengguna.

Menonaktifkan atau menghapus agen tidak otomatis memindahkan seluruh chat lamanya. Tinjau dan atur ulang penugasan chat yang masih aktif jika diperlukan.

### 4. Jam Operasional

![](https://files.readme.io/289cb3f88851771d838bd063b50ff8453066e70bd49394218c99265d0db1f921-Screenshot_2026-10-22_at_17.01.29.png)

Admin dapat mengatur jadwal untuk Senin sampai Minggu.

Pada setiap hari:

1. Aktifkan atau nonaktifkan layanan.
2. Tentukan jam buka.
3. Tentukan jam tutup.
4. Klik **Simpan**.

Ketentuan:

- Jam tutup harus setelah jam buka.
- Hari nonaktif dianggap tutup.
- Zona waktu operasional adalah Asia/Jakarta atau WIB.
- Jadwal disimpan sebagai satu pengaturan tujuh hari.

Saat pengguna memulai chat di luar jam operasional, sistem dapat memberikan balasan otomatis.

Isi balasan menggunakan template slot `luar-jam-kerja`. Jika template tidak tersedia, sistem menggunakan pesan bawaan.

Pengaturan jam operasional bukan tombol untuk menonaktifkan seluruh fitur chat. Chat di luar jam layanan tetap dapat masuk.

### 5. Hari Libur

![](https://files.readme.io/d08ad4380c3a9cf186f01189d565c6ae75479a1566287e7b3c0e034113e34116-Screenshot_2026-10-22_at_17.01.52.png)

Admin dapat:

- Melihat daftar hari libur.
- Memfilter berdasarkan tahun dan bulan.
- Mencari berdasarkan keterangan.
- Menambahkan hari libur.
- Mengubah tanggal atau keterangan.
- Menghapus hari libur.

#### Menambahkan Hari Libur

![](https://files.readme.io/231bb8ee02a7769a7828e6b1b9d6aafa1a567fbed8a9fc4da1d59795b8e2c547-Screenshot_2026-10-22_at_17.02.12.png)

1. Klik **Tambah Libur**.
2. Pilih tanggal.
3. Isi keterangan.
4. Klik **Simpan**.

Ketentuan:

- Tanggal wajib diisi dan tidak boleh duplikat.
- Keterangan wajib diisi, maksimal 255 karakter.
- Tanggal yang terdaftar sebagai hari libur dianggap di luar jam operasional, walaupun jadwal hari tersebut biasanya buka.

Hari libur diatur per tanggal, bukan otomatis berulang setiap tahun.
